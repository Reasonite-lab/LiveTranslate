LiveTranslate 隐私政策

最后更新：2026 年 9 月 29 日

1. 扩展用途

LiveTranslate 用于将用户当前网页中的正文翻译为用户选择的目标语言，支持 AI Dungeon 动态内容和普通网页正文。

2. 处理的数据

当用户启用翻译时，扩展会读取网页中被识别为正文的文本，并将这些文本发送到用户选择的翻译服务以获取译文。扩展不会读取密码框、输入框、可编辑区域、导航栏或对话框。

扩展会通过 Chrome Storage Sync 保存用户的翻译设置，例如启用状态、目标语言、显示方式、翻译服务和扫描延迟。网页正文不会写入该设置存储。

3. 第三方服务

Google Translate 网页服务是默认翻译服务。MyMemory 仅在用户选择或启用备用服务时使用。待翻译的网页正文会传输给相应服务，并受其隐私政策约束。

4. 数据共享与出售

扩展不会出售用户数据，也不会将数据用于与翻译功能无关的目的。除用户选择的翻译服务外，扩展不会向其他第三方传输网页正文。

5. 数据保留与安全

翻译结果只在扩展运行期间用于显示，并可能在浏览器扩展进程内短暂缓存以避免重复请求。扩展不建立用户浏览历史数据库。

6. Chrome Web Store Limited Use 声明

LiveTranslate 对用户数据的使用仅限于提供和改进扩展明确展示的网页翻译功能，并遵守 Chrome Web Store User Data Policy 及 Limited Use 要求。

7. 联系方式

如需咨询隐私问题，请通过 Chrome Web Store 商品详情页提供的开发者联系方式联系发布者。
